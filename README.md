
# Slotly — Appointment Booking Dashboard

Slotly is a modern, responsive appointment management dashboard built using HTML, CSS, and JavaScript. It provides a clean interface to view, create, search, and manage appointments.

## Features

- Modern dashboard UI with dark and light themes
- Responsive layout for desktop, tablet, and mobile
- Appointment statistics and activity chart
- Create new appointments using a form
- Search appointments by client name, email, or service
- Filter appointments by status
- Change appointment status
- Reset demo data
- Custom status indicators
- Interactive dashboard components

## Technologies Used

- HTML5 — page structure
- CSS3 — styling, layouts, responsive design, and themes
- JavaScript — dashboard functionality and interactions
- Google Fonts — DM Sans and Space Grotesk

## Getting Started

### 1. Download or Clone the Project

Download the project files and open the project folder in your code editor.

### 2. Open the Website

Open `index.html` directly in your browser.

Alternatively, in Visual Studio Code, install the Live Server extension, right-click `index.html`, and select **Open with Live Server**.

### 3. Start Using the Dashboard

- Click **New appointment** to create an appointment.
- Use the search box to find appointments.
- Use the status filter to view specific appointments.
- Click the action menu to change an appointment's status.
- Click the theme button to switch between dark and light mode.
- Click **Reset demo data** to restore the original sample appointments.

## Customization

- Edit `index.html` to change dashboard content and layout.
- Edit `style.css` to customize colors, typography, spacing, and responsiveness.
- Edit `app.js` to modify appointment behavior and sample data.

## Current Limitations

This project is a frontend demonstration.

- Appointment changes are stored in browser memory and reset when the page is refreshed.
- No database or backend API is connected.
- Authentication and automatic email or SMS reminders are not implemented.

A backend and database can be added later to support persistent appointment storage, secure login, and notifications.
